# 一級建築士 設計製図 対策アプリ

一級建築士 設計製図試験の対策用Webアプリです。単一HTMLで動作し、インストール不要・オフラインでも利用できます。

**公開URL: https://fkol-apps.github.io/ikkyu-kenchikushi-seizu/**

## 設計方針

本番の試験にアプリは持ち込めません。このアプリは**本番に持ち込む道具ではなく、本番で頭の中で回す手順を体に刷り込むための教材**として設計しています。

## 4つの機能

### ① 計画の要点等トレーニング（50設問）
建築計画13／構造計画12／設備計画13／環境・省エネ6／防災・避難6。
自分の言葉で書いた解答に必須キーワードが含まれているかを自動判定します。
表現が模範解答と違っても、観点さえ押さえていれば満点になります。

### ② 法規計算ドリル／エスキス検算
ランダムな設計条件から、建蔽率の限度・建築面積の上限・容積率の限度・延べ面積の上限・
最も厳しい高さ制限を**自分で計算して入力**し、答え合わせします。項目別の正答率が蓄積されます。
エスキス検算は、自分のプランの答え合わせとボリュームの相場観づくりに使います。

### ③ 工程タイマー
6時間30分を10工程に刻んで計測します（読み取り25／エスキス110／記述40／作図180／見直し35分）。
実績を溜めると工程ごとの中央値＝**あなた自身の標準時間**が算出され、時間割に反映できます。
作図時間は短縮する対象ではなく、実測して固定する対象という考え方に基づいています。

### ④ 提出前チェックリスト（40項目）
ランクⅣ（一発失格）につながる致命項目13を含む40項目。
本番は頭の中でリストを回すため、カテゴリ名だけから項目を挙げる「想起テスト」を備えています。

## 注意

収録している設問・チェック項目は、過去の出題傾向をもとに作成した**オリジナル**です。
実際の試験問題および標準解答例の複製ではありません。

法規計算は建築基準法第52条第1項・第2項（前面道路による制限を含む）までの対応で、
特定道路の緩和・天空率・公園等による緩和は含みません。検算の補助としてご利用ください。

法令・基準の記述は作成時点のものです。受験にあたっては必ず最新の法令および
公益財団法人建築技術教育普及センターが公表する公式資料をご確認ください。

学習データはブラウザのlocalStorageに保存されます（端末ごと・サーバー送信なし）。
